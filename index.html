Built by makers, for classrooms

H&A Tech is a two person team. We design and prototype every kit ourselves, then rebuild it as a lesson educators and parents can run alongside their children for fun learning.

Featured kit: HoloCube

Grades 6 to 12 Electronics + optics 45 to 60 min build

A floating image, built from a beam splitter and a bit of code

Students wire an ESP32 and OLED display into a 3D printed enclosure, then use a beam splitter cube to project a single image into what looks like a hovering 3D object. It's a working lesson in optics, circuits, and embedded electronics in one build.

Every kit includes the printed enclosure, display, microcontroller, beam splitter cube, hardware, and a full instruction set ready to teach from.
